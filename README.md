## 🚀 Featured Projects

### 🤖 [Idea2Build — AI-Powered Software Engineering Project Mentor](https://github.com/Kavya-Dhanapal/idea2_Build.git)
An interactive, full-stack developer workspace that uses Google Gemini to mentor developers. It turns abstract project ideas into detailed technical blueprints, implementation steps, recommended tech stacks, directory wireframes, database schemas, REST APIs, and personalized course roadmaps based on the developer's current skill level.

**Tech Stack:** Java 21 · Spring Boot · MongoDB · React · Gemini API
🔗 [Repository](https://github.com/Kavya-Dhanapal/idea2_Build.git) &nbsp;|&nbsp; 🌐 [Live Demo](https://idea2build-661587666785.asia-southeast1.run.app/)

---

### 🏙️ [CivicFix — Smart City Complaint Management System](https://github.com/Kavya-Dhanapal/CivicFix.git)
In many cities, people struggle to report problems like potholes, garbage accumulation, broken streetlights, or water leakage, and complaints are often lost or delayed. CivicFix provides a digital platform where citizens can easily report issues, government authorities can manage complaints, and users can track the progress of their complaints.

**Tech Stack:** Java · Spring Boot · MySQL
🔗 [Repository](https://github.com/Kavya-Dhanapal/CivicFix.git)

---

### 🆘 [Disaster Relivon System](https://github.com/Kavya-Dhanapal/Disaster-Relivon-System.git)
A web-based platform designed to help people report and manage disaster-related emergencies such as floods, earthquakes, or accidents. The system allows users to submit requests for help, while authorities or volunteers can track and respond to these requests efficiently.

🔗 [Repository](https://github.com/Kavya-Dhanapal/Disaster-Relivon-System.git)
